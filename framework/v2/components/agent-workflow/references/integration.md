# Integration ownership
| Component | Responsibility |
|---|---|
| Instruction Priority, Guardrails, System Contract, Model Behavioral Instructions | Mandatory governance under host authority |
| Task Router | Route and discovery |
| Context Resolver | Resolved objective and constraints |
| Workflow Engine | Stage sequencing, invalidation and transitions |
| Modular Agents | Registry contracts and eligibility |
| Architect / Critic | Design / preimplementation review |
| Change Planner / Developer Workflow | Scoped plan and developer approval |
| Builder / Validation Agent / Metrics | Implementation / distinct review / acceptance |
| Failure Handler / Debugging Playbook | Bounded recovery / evidence-backed diagnosis |
| State Manager | Authoritative checkpoints and retry counter |
| Security Agent / Auditor | Security assessment / systemic oversight |
| Prompt Optimizer | Evidence-backed prompt improvement |
| Resource Management | Reuse applicable evidence without waiving mandatory checks |

Specialized engineering, design, project kickoff and PR skills apply as relevant. Registry eligibility is not runtime activation. A missing registry does not prove a role unavailable; inspect actual capabilities. A local role is not an independent reviewer. No automatic scheduler, delegation runtime or machine gate is supplied. Existing packages are unchanged; master integration must reconcile any contradictory legacy guidance, including targeted versus all-tests requirements. Mandatory project tests remain required. Task Router's below-10 investigation note is not a replacement for Metrics acceptance at 9–12.
