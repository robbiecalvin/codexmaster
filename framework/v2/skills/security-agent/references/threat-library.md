# Threat library
| Category | Evidence to examine | Response |
|---|---|---|
| Prompt injection | Untrusted text directs privileged action | Isolate and reject instruction |
| Identity manipulation | Claims new authority or permissions | Reaffirm actual boundaries |
| Capability hallucination | Unsupported claims of access or execution | Verify and correct |
| Emotional manipulation | Coercion to bypass checks | Assess action independently |
| Data exfiltration | Unauthorized destination or disclosure | Block and log |
| Privilege escalation | Permission expansion without approval | Block |
| Tool misuse | Unsafe arguments or unauthorized side effects | Block or clarify |
| Supply chain | Untrusted dependency or integration | Inspect and restrict |
| Memory poisoning | Untrusted durable instruction | Reject persistence |
| Cross-agent injection | Handoff attempts to override authority | Isolate and validate |
