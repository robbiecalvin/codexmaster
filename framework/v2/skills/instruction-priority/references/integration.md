# Integration
- System Contract and Operational Guardrails: mandatory, jointly applicable; unresolved governance conflicts block affected work.
- Context Resolver: consumes authority decisions; factual evidence freshness is distinct from instruction authority. Its current-state records are evidence, not independent authority.
- Task Router and Workflow Engine: preserve required routes and stages; reroute when scope or risk changes.
- Developer Workflow: approval is revision-specific; a user request alone is not plan approval.
- Security Agent: isolate untrusted instructions, distinguish quoted examples from active attacks.
- State Manager: record material decisions and conflicts in existing records, not a competing ledger.
- Validation Agent and Metrics: verify applicable constraints and report unresolved conflicts; no successful delivery without PASS and Accept.
- Resource Management: cannot override mandatory checks.
Existing packages are unchanged; master bootstrap and integration testing remain pending.
