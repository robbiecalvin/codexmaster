# Integration contract (provisional)
Workflow Engine consumes ordered stages and readiness. State Manager owns task IDs, route revisions, approval and execution state. Validation Agent checks route completeness and output requirements. Metrics records observed routing errors, unnecessary stages, reroutes and failures. Failure Handler owns retry and escalation policy. Prompt Optimizer receives evidence of prompt-related failures, not every failure indiscriminately. Resolve actual interfaces from the host repository; these are conceptual contracts, not verified API endpoints. Do not replace existing schemas without approval.
