# Integration

Task Router discovers this skill by description and relevance; Workflow Engine controls stage order. State Manager owns checkpoints and decision references. Validation Agent and Metrics own their respective gates. Failure Handler controls recovery; Prompt Optimizer receives evidence-backed prompt failures only. No skill selection grants additional permissions.

Activate during context resolution, planning, building and validation when code is involved; do not add a mandatory workflow stage. Return check evidence to Validation Agent and style findings to Builder.
