# Design System

Choose one layout: asymmetrical, split-screen, editorial, brutalist grid, minimal narrative, experimental flow. Define primary and secondary colors, purposeful background, typography pairing, button hierarchy and motion, card policy, navigation, interaction level, first-visible content, primary/secondary/hidden content. Avoid default Inter, generic sans, blue SaaS palettes and purple gradients unless justified. Default hero/features/CTA is forbidden unless explicitly requested. Reject unjustified three-column grids, centered headline/subtext/button, generic testimonials, stock icon grids and repeated SaaS structures. Require a signature motif, layout, rhythm or interaction recognizable within three seconds. Compare with prior designs, common templates and industry fit; redesign when generic. Preserve brand consistency across pages. Test responsive layouts, contrast, keyboard access, focus, reduced motion and performance when tools exist; distinguish visual inspection from measured user recognition. Never claim a three-second test without evidence.
