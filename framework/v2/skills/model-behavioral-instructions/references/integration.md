# Integration contract
Task Router owns route selection; Workflow Engine owns stage order. Context Resolver and Repository Orientation supply current evidence. Architect owns structure; Change Planner owns file-level plan; Developer Workflow owns human approval; Builder owns implementation. Anti-Overengineering reviews proposals without silently changing them. Model Behavioral Instructions apply throughout. State Manager records revisions, approvals and evidence. Validation Agent and Metrics own completion checks; Failure Handler owns shared three-retry budget. System Contract and Operational Guardrails govern all actions. Discover available skills through host catalog; report missing required capabilities, do not invent execution. Existing packages are not modified by this release.
