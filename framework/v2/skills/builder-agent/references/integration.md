# Integration
Task Router owns route; Context Resolver owns active requirements; Architect and Critic own required plan reviews; Change Planner owns file-level plan; Developer Workflow owns approval gate. Builder consumes these records, never substitutes its own approval. Workflow Engine owns sequencing and rerouting. State Manager owns checkpoint and retry persistence. Failure Handler owns recovery; Security Agent and Guardrails apply throughout. Resource Management preserves valid evidence but cannot waive required tests. Validation reviews the exact output revision after Builder; Metrics scores only eligible validated outputs. Pull Request Rules apply to authorized delivery operations. Auditor reviews systemic issues. Discover compatible skills dynamically; missing mandatory inputs block execution. No new mandatory stage is introduced. Host controls take precedence. Existing packages are not modified.
