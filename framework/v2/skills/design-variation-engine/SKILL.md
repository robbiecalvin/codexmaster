# Design Variation Engine

Choose layout (asymmetrical, split-screen, editorial, brutalist grid, minimal narrative, experimental flow), density (dense, balanced, minimal), tone (corporate, playful, dark cinematic, raw brutalist, futuristic), typography (display-heavy, editorial serif, mono technical, clean sans hierarchy), interaction (static, micro-interactions, high-motion). Record normalized five-axis fingerprint plus visual identity (palette, type pairing, motif) and layout/identity/interaction triple. Check both fingerprints against available full project history; inspect last five projects for dominant layout repetition. Prefer intentional deterministic selection, or record seed if randomness requested. Reject duplicate combinations across distinct projects and regenerate with different parameters, bounded to three attempts unless governing recovery policy differs. If no suitable option remains, report blocker and seek direction. Missing history means uniqueness unverified. Same-brand pages may share identity; vary composition within brand. Never sacrifice accessibility or requirements for novelty.
