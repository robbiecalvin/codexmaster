# Design Memory

Retrieve relevant patterns before design selection. Record category, name, reproducible structure, cause/effect, applicable contexts, avoid conditions, source, evidence and verification status. Store only actionable high-signal lessons; do not duplicate Design System rules. Treat supplied seed patterns as guidance, not independently verified outcomes. Update after evidenced differentiation, consistent performance, usability improvement or repeated failure. Mark obsolete entries superseded rather than silently deleting history. Separate brand-specific patterns from cross-project defaults. Link project decisions via State Manager; send verified lessons to Prompt Optimizer. Exclude secrets and personal data.

## Shared execution contract
Use hybrid autonomy: inspect, propose, test and record within authorized scope; obtain approval for material brand changes, permanent rules, destructive edits or deployment. Host instructions and safety govern. Discover skills through Task Router; resolve context before execution. Do not add mandatory stages. State Manager owns checkpoints; Workflow Engine owns stage order; Validation Agent and Metrics own acceptance. Report missing tools, evidence and blockers; never fabricate results.

Read references and templates when relevant. Use platform adapter matching host.
