# Seed design patterns (user-supplied; empirical verification pending)
| Pattern | Structure / rationale | Use or limitation |
|---|---|---|
| Asymmetrical hero | Left content, offset visual, staggered sections, irregular rhythm; visual tension | Portfolios, personality-led tools |
| Editorial split | 60–70% text, 30–40% visual, vertical rhythm | Storytelling, long-form |
| Brutalist minimal | Hard edges, visible grid, 1–2 colors, mono/system type | Avoid where trust or corporate tone conflicts |
| Dark restrained | Near-black #0a0a0a, sparse accent, sharp type | Avoid if playful identity conflicts |
| Hover elevation | Slight lift, 100–150ms delay, soft easing | Avoid dense layouts and stacked effects |
| Scroll reveal | Staggered fade/slide | Limit motion; mobile performance and reduced motion |
| Generic hero + cards | Centered headline, CTA, three equal columns | Replace with staggered or narrative flow |
| Gradient overload | Gradients everywhere weaken hierarchy | Solid base, purposeful emphasis |
| Card overload | Uniform boxes flatten hierarchy | Mixed sizes and narrative sections |
| Buttons | Primary, secondary, tertiary emphasis | Intentional hierarchy |
| Typography | Serif/sans or mono/sans contrast | Avoid default generic pairing |
| Spacing | Compression and expansion | Avoid mechanical uniformity |
