# Scoring
Prefer the owning Metrics contract. Fallback weights (proposed): clarity 15, intent alignment 15, constraints 10, accuracy 20, consistency 15, efficiency 10, architecture compatibility 10, scope control 5. Rate each 0–10 with evidence: 0 fails, 5 partially meets, 10 meets defined criteria across the test set. Missing evidence is unverified; do not compute a complete score from incomplete dimensions. Weighted score = sum(weight × rating)/100. Below 10 triggers review. Accept a candidate only when required checks pass, no material regression occurs, and improvement is demonstrated; otherwise retain baseline. Use matched inputs, model/settings and evaluation rubric. Separate observed results from expectations.
